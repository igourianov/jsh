# Kong Inc.

**Company Type:** SaaS/Platform (API Management & AI Gateway)
**Stage:** Scale-up (Unicorn since 2020, $2B valuation)
**Size:** 600-879 employees across 25+ countries
**Remote Policy:** Remote-first with flexible/hybrid options; HQ in San Francisco

## Quick Take
- Strong open-source DNA with flagship Kong Gateway (42.7k GitHub stars) and active community of 160,000+ developers
- Pivoting heavily into AI/LLM gateway space - strategic positioning for agentic AI future
- Solid financials with $146M revenue in 2024 (up from $100M in 2023) and continued investor backing

## Milestones
- **2009**: Founded in Milan, Italy as Mashape by Augusto Marietti, Marco Palladino, and Michele Zonca
- **2011**: Early funding from Jeff Bezos, Russell Siegelman and angel investors
- **2015**: Open-sourced Kong Gateway, pivoting from API marketplace model
- **2017**: Sold Mashape to RapidAPI, rebranded to Kong Inc.
- **2020**: Reached unicorn status ($2B valuation); acquired Insomnia (API design tool)
- **2022**: Acquired Fourkeys
- **2023**: Surpassed $100M ARR
- **2024**: Raised additional funding (Series E, Tiger Global/Balderton Capital lead); reached $146M revenue
- **September 2025**: Acquired OpenMeter for usage-based billing capabilities

## Company & Product

Kong Inc. is the creator of Kong Gateway, the world's most widely adopted open-source API gateway. The company has evolved from its origins as an API marketplace (Mashape) to become a comprehensive API platform provider.

**Core Products:**
- **Kong Gateway**: Open-source API gateway (Apache 2.0) for proxying, routing, load balancing, and authentication
- **Kong Konnect**: Cloud-hosted unified platform for API management, service mesh, and ingress control
- **Kong AI Gateway**: Specialized gateway for LLM/MCP traffic with multi-provider support (OpenAI, Anthropic, AWS Bedrock, Azure AI)
- **Insomnia**: Open-source API design and testing tool
- **Kuma/Kong Mesh**: Open-source and enterprise service mesh solutions

**Scale:**
- 400 billion+ API calls processed daily
- 700+ enterprise customers
- 160,000+ community members
