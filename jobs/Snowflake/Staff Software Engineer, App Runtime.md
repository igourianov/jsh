## Company

Snowflake Computing is a cloud data platform company, positioning itself as building the "agentic enterprise." The App Runtime team specifically builds a platform enabling any Snowflake user to build and deploy web applications (Node.js first) directly within Snowflake, inheriting the platform's security, governance, lineage and access controls. The product is in public preview, aiming to become Snowflake's native app-hosting layer alongside adjacent teams covering containers, networking, Cortex AI and security.
